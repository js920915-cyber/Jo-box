# 테두리 시안 QA

- B01~B05 개별 PNG 5장, 모두1080×1350. 같은 가운데 정렬 3번 카드의 문구/내용/서체/배치이며 외곽 SVG만 변경.
- 원본5장을 실제 열어 비교. 글·설명을 가리지 않는 약29~41px의 가장자리 장식. 본문 안전 여백과 가운데 정렬 유지.
- 360px 축소본5장을 확인. 강한 파랑/검정 장식 대신 회청색/페일 블루로 본문보다 낮은 대비.
- 렌더 검사: 5장 동일 텍스트, text-align=center, 안전 영역, 해상도 PASS. qa/layout-check.json에 기록.
- SVG는 코드 편집 가능한 독립 레이어이며 이미지 생성 도구로 만든 소재가 아님.
- 새로운 임상 내용 없이 기존 카드 재사용. 기존6장/영상틀은 특정 시안 선택 전 그대로 보존. 전체 카드뉴스를 변경했다고 주장하지 않음.
