# 테두리 디자인 시안 5종

동일한 가운데 정렬 3번 카드에 **외곽 장식만** 바꿔 적용한 비교 시안. 모든 PNG는 1080×1350. 기존 게시용 카드 6장에는 아직 특정 테두리를 일괄 적용하지 않았다.

| 파일 | 디자인 | 특징 |
|---|---|---|
| B01.png | 얇은 라운드 프레임 | 2px 회청색 선, 차분한 기본형 |
| B02.png | 네 모서리 포인트 | 모서리만 3px 선, 개방적인 인상 |
| B03.png | 상하 열린 프레임 | 좌우 외곽선을 생략하고 상하에만 장식 |
| B04.png | 이중 헤어라인 | 1.5px 두 선, 종이 액자 같은 정돈감 |
| B05.png | 부드러운 페일 블루 테두리 | 연한 12px 띠 + 1.5px 윤곽 |

모든 장식은 아트보드 가장자리 약 29~41px 영역에서만 사용한다. 가운데 정렬/본문/의학적 문구는 동일하며 로고·페이지 번호·하단 출처를 추가하지 않았다. SVG가 독립 편집 레이어라 색·선 두께·모서리 반경을 수정할 수 있다.

디자인 추천: **B02**는 눈에 덜 띄면서 여백을 살리고, **B01**은 가장 안정적인 통일감을 준다. 선택 시 사진·텍스트·영상 카드 모두에 같은 외곽 좌표로 적용 가능하다.

소스: source/build.py, source/B01~B05.html, source/cards.css, source/render.cjs. 기준 카드/임상 근거는 ../achilles-elongation-v2/의 caption.md와 research/에 보존되어 있다. 이번 작업은 테두리 디자인 비교이며 신규 임상 주장은 없다.
