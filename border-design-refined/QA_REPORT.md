# 발전 시안 QA

기준: 사용자 선호 B05 페일 블루 테두리에서 외곽 장식만 발전. 가운데 정렬과 카드 본문을 보존하며 원본 텍스트가 5종 모두 동일함을 자동 검사했다.

- C01~C05: 5개 독립 HTML 아트보드와 개별1080×1350 PNG.
- 원본5장 및360px 축소본5장 실제 열어 확인. 외곽 장식은 본문/제목에 겹치지 않으며 안전 여백 유지.
- 글의 위치/크기/내용 고정. 그라데이션, 코너 곡선, 사선, 유기적인 옆선, 점선 표면으로 시각 차이 확인.
- 안전 영역·가운데 정렬·동일 텍스트·해상도 검사 PASS. qa/layout-check.json 보존.
- 모든 새 자산은 자체 SVG/코드. 사진·연구 Figure·새 임상 주장은 없음. Noto Sans KR/OFL 동봉.
- 이전 시안/게시용 카드6장은 그대로 보존. 특정 시안을 전체 카드에 확정 적용하지 않았다.
