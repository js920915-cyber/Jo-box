# B05 발전 시안 5종

이전 B05 페일 블루 프레임을 발전시킨 외곽 디자인 비교. 원본 카드의 내용·가운데 정렬·폰트/크기/위치는 동일하며 장식만 변경했다. 전체1080×1350, SVG/HTML/CSS 편집 가능.

| ID | 형식 | 변화 |
|---|---|---|
| C01 | 블루 그라데이션 | 색 농도가 달라지는 띠·이중 윤곽·작은 상하 포인트 |
| C02 | 겹친 코너 곡선 | 대각선 두 모서리에 겹친 곡선·작은 점 |
| C03 | 스포츠 코너 | 두 사선 모서리와 짧은 사선 장식 |
| C04 | 유려한 곡선 | 옆선을 미세하게 휘게 한 유기적인 외곽 |
| C05 | 페이퍼 프레임 | 넓은 연한 띠 안에 규칙적인 작은 점 |

기존 카드뉴스 본편은 특정 시안을 고르기 전 그대로 보존한다. 새 임상 내용 없음. 기존 근거는 ../achilles-elongation-v2/research/에 있다. 장식은 자체 SVG이며 연구/타인 사진을 새로 사용하지 않았다.

빌드: source/build.py. 렌더: source/render.cjs(번들 Playwright/Sharp와 Chrome). source/C01~C05.html에서 독립 SVG 레이어와 텍스트를 수정할 수 있다. 폰트/OFL 동봉.
