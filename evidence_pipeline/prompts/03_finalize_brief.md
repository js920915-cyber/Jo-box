# 03 — 연구 검토 후 Codex 전달 파일 확정
사용 위치: 연구를 진행한 ChatGPT. templates/topic/research/ 네 양식을 첨부하면 형식이 맞춰진다.

## 실행 프롬프트
앞선 조사 결과와 내가 추가한 의견을 통합해 Codex 전달용 근거 파일을 만들어줘.
기본 대상과 핵심 질문은 앞선 대화에서 정한 것을 유지해줘.
다음 순서로 실제 핵심 주장·수치·원문 위치를 재검토해줘.
1. 지침과 연결 원문
2. 수치·단위·분모·비교·시점
3. 인과/관련과 실제 연구 대상에 대한 일반화
4. 사용자 필수 의견 누락
5. 독자가 할 행동과 반드시 남겨야 할 조건

[파일]
1. sources.md — S ID, 서지정보, 설계·대상·결과·한계·확인 범위·원문 위치·확인일
2. claims.md — C ID, U ID 연결, S ID/원문 위치, 허용 게시 문장, 필수 조건, 금지 표현, 검증 상태
3. evidence_review.md — 발견 문제, 수정 내용, 해결/미해결, 직접 대조한 근거, 검색/접근 한계
4. research_brief.md — 제작용 요약, 한 문장 답, 핵심 메시지 3~5개, 필수 의견 반영표, 근거 ID, 실제 적용, 제외 내용

상태는 VERIFIED/REVISE/BLOCK을 사용하되 VERIFIED를 높은 근거 확실성과 혼동하지 마.
초록에서 확인한 제한된 결과는 접근 한계를 남기고 그 범위만 허용해줘.
근거가 없는 숫자와 문장은 삭제하거나 BLOCK 처리해줘.
미해결 BLOCK이 있으면 RESEARCH_READY로 확정하지 말고 무엇이 더 필요한지 알려줘.
사용자 의견을 무리하게 채택하지 말고 미반영 사유를 남겨줘.
파일마다 버전과 작성/검증일을 기록하고 C/S ID를 일치시켜줘.
대화 인용 표시에만 의존하지 말고 실제 DOI/공식 URL을 기록해줘.

가능하면 네 개의 UTF-8 Markdown 파일을 내려받을 수 있게 만들어줘.
파일 생성이 안 되면 ‘파일명 + 완전한 Markdown 코드 블록’을 각각 제공해줘.
이는 근거 준비 상태 확정이며, 사용자의 카드 내용 확정 기록은 별도로 남겨야 해.
아직 카드뉴스 이미지나 완성 디자인은 만들지 마.
