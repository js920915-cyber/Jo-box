# 06 — 내용 확정 후 디자인과 파일 제작
사용 위치: 수정 완료한 Codex 대화.

## 실행 프롬프트
content/<slug>/storyboard.md의 현재 문안을 확인했고 이 내용으로 디자인을 진행해줘.
내가 확정한 범위는 현재 카드별 내용이며, 새 의학적 주장·수치·처방을 임의로 추가하지 마.

1. 해당 storyboard/Research Brief 버전과 이번 내 발언의 범위를 approval_log.md에 기록해줘. 이미 요청한 디자인 진행을 다시 물어보지 마.
2. evidence_pipeline의 디자이너 지침, 기존 DESIGN_SYSTEM.md, CARDNEWS_WORKFLOW.md, 실제 references/ 이미지를 확인해줘.
3. 흰 배경, 검정 굵은 제목, 넓은 여백, 제한된 블루 강조, 주제와 연결되는 큰 사진/도식으로 만들어줘.
4. 기본 1080×1350 개별 PNG이며 실제 장수는 확정된 문안에 따라줘. 상단 로고·페이지 숫자·편집/공유 UI는 제외해줘.
5. 임상 사진은 원문 동작·랜드마크·각도·기구를 확인하고 실제 사용권을 assets/asset_manifest.md에 기록해줘. 참고 이미지 접근과 게시 재사용 권한을 구분해줘.
6. 임상 문장·숫자·조건을 디자인 때문에 몰래 바꾸지 마. 오타·줄바꿈·뜻이 같은 축약은 진행하고 기록해줘. 의미 변경이 필요하면 영향받는 주장·카드만 검증하고 변경안을 보여줘.
7. source/에 재현 가능한 편집 소스, exports/에 개별 카드, caption.md에 자세한 설명·실제 DOI/공식 출처를 작성해줘.
8. 원본과 360px 축소 화면으로 각 카드의 읽힘/잘림/사진 대응을 실제 확인해줘. 파일 해상도·장수·소스 존재도 확인해줘.
9. 연구·수치·대상·인과 표현·사용자 필수 의견·이미지 자세/사용권·파일 검수 결과를 QA_REPORT.md에 기록해줘.
10. 실제 파일이 생성되기 전에는 제작 완료라고 하지 마. 도구·자료가 막히면 가능한 결과와 필요한 자료를 구분해줘.

완료 후 개별 PNG, 편집 소스, 캡션, 사용 근거와 남은 문제를 제공해줘.
SNS에 자동 게시하지 마.
