# 01 — ChatGPT에서 근거 조사
사용 위치: ChatGPT의 일반 파일 분석 대화 또는 심층리서치.
대괄호 내용만 이번 주제에 맞게 바꾼 뒤 실행한다.
여러 논문 비교는 심층리서치를 활용할 수 있다. 제공되지 않으면 가능한 검색/파일 분석 범위를 밝힌다.

## 실행 프롬프트
너는 R스포츠재활센터의 근거기반 재활 콘텐츠 리서처다.
이번 목적은 카드뉴스의 근거를 충분히 확보하는 것이다.
지금은 디자인이나 최종 카드 문구를 만들지 말고 연구 조사 보고서와 제작용 근거 후보를 작성해줘.

[입력]
주제: [주제]
핵심 질문: [독자가 실제로 궁금해할 질문]
대상: [성인/유소년, 손상·수술 여부, 단계, 종목]
내가 반드시 포함하고 싶은 내용:
- U01: [필수 의견 1]
- U02: [필수 의견 2]
- U03: [필수 의견 3]
기존 글과 차별화할 점: [있으면 작성]
독자가 글을 읽고 할 행동: [원하는 행동]
제공 자료: [첨부 PDF, 논문 제목, DOI, PMID, 링크 / 없으면 직접 검색]

[조사 순서]
1. 관련 가이드라인·합의문·공식 프로토콜을 먼저 확인하고 발행 연도, 개정 여부, 대상, 권고 위치를 기록해줘. 적합한 지침을 못 찾으면 검색 범위를 밝히고 직접 관련 문헌으로 보완해줘.
2. 지침에 인용된 원문을 추적하고 질문에 직접 답하는 연구·문헌고찰을 비교해줘. 지침 이후 연구도 관련성을 판단해 포함해줘.
3. 원문이 막히면 제목/DOI/PMID로 PMC, 기관 리포지터리, 저자 공개본, Unpaywall, Scholar의 합법적 공개본을 찾아줘.
4. 실제 확인 범위를 ‘Methods/Results/표 확인’, ‘초록만 확인’, ‘서지정보만 확인’처럼 구분해줘. 접근 가능한 원문과 실제 읽은 구간도 구분해줘.
5. 검색·파일 접근이 불가능하면 가능한 자료만 분석하고 최신성 또는 원문 검증을 완료했다고 하지 마.

[추출할 내용]
각 연구에 S01, S02… ID를 붙여 다음을 작성해줘.
- 제목, 저자, 연도, DOI/PMID 또는 공식 URL
- 연구 설계, 대상, 표본, 중재/비교, 추적기간, 결과 지표
- 실제 결과와 수치: 단위·분모·비교·시점·효과 크기와 불확실성
- 핵심 결과가 있는 페이지/표/그림/절과 확인일
- 주요 한계와 우리 대상에 적용 가능한 범위

[검증 기준]
통증·근력·근비대·기능·재손상·복귀를 서로 다른 결과로 구분해줘.
관련성을 인과로, 기전을 임상 효과로, 연구 프로토콜을 보편 처방으로 바꾸지 마.
수치가 지침 권고/연구 결과/연구 프로토콜/검증 계산/임상 제안 중 무엇인지 표시해줘.
RR/OR/HR을 구분하고 절대위험은 원자료가 있을 때만 제시해줘.
상충된 근거를 숨기지 말고 대상·방법·결과 차이를 비교해줘.
공식 근거 등급이 없으면 임의 GRADE 점수를 만들지 마.

내가 넣고 싶은 U01… 의견도 검증해줘.
지지됨/조건부 가능/근거 부족/범위 밖으로 나누고 허용 표현과 제외 사유를 설명해줘.
나의 의견을 증명하기 위해 유리한 연구만 고르지 마.

[출력]
1. 한 문장 답과 적용 범위
2. 연구별 추출 표
3. 카드뉴스 핵심 주장 후보 C01…와 S ID 연결
4. 사용자 필수 의견 반영표
5. 표현하면 안 되는 단정과 숫자
6. 실제 적용에 연결할 포인트
7. 미확인 자료·추가 확인 질문
8. 실제 클릭 가능한 참고문헌 링크

원문은 위치 확인에 필요한 짧은 구절만 인용하고 결과는 한국어로 요약해줘.
대화 전용 인용 토큰 외에 DOI/공식 URL을 함께 남겨줘.
