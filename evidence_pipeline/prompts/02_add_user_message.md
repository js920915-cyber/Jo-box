# 02 — 연구 후 내가 넣고 싶은 내용 추가
사용 위치: 연구를 진행한 ChatGPT 대화.

## 실행 프롬프트
앞선 연구 보고서에 다음 내 의견을 추가하고 근거를 재검토해줘.

[추가 또는 수정 의견]
- [의견]
- [의견]
[강조 정도]
- 반드시 전달할 질문: [내용]
- 강조하고 싶은 해석: [내용]
- 빼고 싶은 내용: [내용]

의견에 U ID를 이어서 붙이고 각 항목을 실제 연구 결과 / 가능한 해석 / 임상 관찰 / 근거 미확인으로 구분해줘.
주장을 더 강하게 단정하지 말고 대상·결과·조건을 확인해줘.
직접 근거가 부족하면 단정문 대신 질문·조건부 표현·제외 중 적절한 방식을 제안해줘.
추가 검색이 필요하면 해당 주장에 한정해 조사해줘.
반영 전/후 문장, 관련 C/S ID, 카드에 넣을 수 있는 표현, 필요한 조건, 제외 사유를 표로 보여줘.
아직 디자인하지 마.
