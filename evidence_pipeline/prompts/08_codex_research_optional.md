# 08 — 선택: Codex 내부에서 조사부터 문안까지
사용 위치: 검색/파일 접근이 가능한 Codex 프로젝트.
독립 에이전트 설치 없이 한 대화에서 역할을 순서대로 수행한다.

## 실행 프롬프트
이번 주제는 Codex 내부에서 근거 조사부터 카드별 문안까지 진행해줘.

주제: [내용]
대상: [내용]
핵심 질문: [내용]
필수 의견: [내용]
제공 PDF/링크: [내용]
주제 경로: content/<slug>/

evidence_pipeline/README.md와 WORKFLOW.md를 읽어줘.
Evidence Researcher → Scientific Reviewer → Content Strategist 역할 지침을 순서대로 적용해줘.
웹 검색·원문 접근 가능성을 먼저 확인하고, 불가능하면 제공 자료만 분석한다고 알려줘.
최신성/원문을 확인하지 못했다면 확인 완료라고 하지 마.
가이드라인 우선·원문 추적·수치·대상·인과 관계를 검증하고 실제 근거 파일 4개를 만들어줘.
내 필수 의견도 검증하고 반영/조건부/제외를 기록해줘.
단순 자기 재독을 독립 전문가 검토라고 보고하지 마.
연구가 준비되면 카드별 실제 제목·본문·조건·C/S ID를 storyboard.md에 작성해줘.
카드별 문안 전체와 내 의견 반영표를 보여주고 디자인 전 내용 검토 지점에서 마쳐줘.
지금은 이미지 생성·디자인 렌더링·SNS 게시를 하지 마.
