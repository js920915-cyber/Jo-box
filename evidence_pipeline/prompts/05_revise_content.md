# 05 — 디자인 전 내용 수정
사용 위치: 카드별 문안을 만든 Codex 대화.

## 실행 프롬프트
content/<slug>/storyboard.md의 문안을 다음처럼 수정해줘.

[수정]
- [카드 번호 또는 문장]: [수정 의도]
- [반드시 추가할 질문·설명]
- [삭제할 내용]

뜻이 같은 표현 편집인지 새로운 의학적 주장인지 먼저 구분해줘.
표현 편집은 해당 문안만 고치고, 새 주장·수치·처방이면 실제 근거를 확인해 sources/claims/review/research_brief도 함께 갱신해줘.
내 의견을 입증하려고 없는 근거를 만들지 마.
직접 근거가 없으면 조건부 표현이나 제외안을 제시해줘.
C/S ID와 U ID를 유지하고 storyboard 버전을 올려줘.
변경 전/후 문장, 추가 설명, 남겨야 할 조건, 사용자 의견 반영 위치를 보여줘.
아직 디자인하지 마.
