# 04 — Codex에서 카드별 내용만 먼저 작성
사용 위치: 자료를 전달한 기존 Codex 프로젝트.
<slug>를 실제 주제 폴더명으로 바꾼다.

## 실행 프롬프트
content/<slug>/의 자료로 카드뉴스 문안을 먼저 만들어줘.

1. evidence_pipeline/README.md, WORKFLOW.md, roles/content_strategist.md를 읽어줘.
2. brief.md, user_notes.md, research/sources.md, claims.md, evidence_review.md, research_brief.md를 실제로 읽어줘.
3. 아직 주제 폴더가 없으면 evidence_pipeline/templates/topic/을 복사해 만들어줘. 제공받은 실제 파일은 그 위치에 보존하고 빈 양식으로 덮어쓰지 마.
4. C/S ID 연결과 검증 상태를 확인하고 미해결 BLOCK이 있으면 해당 주장부터 수정·제외해줘. 직접 확인할 자료가 없으면 확인 불가를 보고해줘.
5. 기존 source/exports/가 있다면 읽어 현재 상태를 파악하되 이번 요청은 문안 작성까지만 진행해줘.

기본 6장이며 내용에 맞게 장수 변경을 제안할 수 있어.
각 카드에 다음을 작성해줘.
- 역할/독자가 얻을 답
- 실제 게시할 제목
- 실제 게시할 본문
- 같은 카드에 남겨야 하는 대상·조건·한계
- C/S ID와 원문 위치
- 시각자료 아이디어
- 캡션에 옮길 상세 설명

내용이 부실해지지 않게 ‘왜 그런지’와 ‘무엇을 확인/실행할지’를 전체 흐름에 포함해줘.
‘평가가 중요’나 장비 이름만 반복하지 마.
한 카드 한 논점, 전문용어는 쉬운 설명과 연결해줘.
후킹 제목도 근거보다 강한 주장으로 만들지 마.
이미지 생성·디자인 코드·PNG 렌더링은 지금 진행하지 마.

storyboard.md에 문안 버전을 기록하고 user_notes.md에 U ID별 반영 카드/조건/제외 사유를 갱신해줘.
나에게 카드별 문안 전체와 사용자 의견 반영표, 미해결 쟁점을 보여줘.
내용 확인 후 디자인으로 진행할 수 있게 해줘.
