# 기존 CARDNEWS_WORKFLOW.md 통합 요령
1. 기존 파일을 시각·의학·파일 검수 플레이북으로 유지한다.
2. 서두와 Quick Start의 ‘한 줄로 모든 Gate 실행’은 다음으로 교체한다.
   ‘주제 입력으로 근거 조사와 카드별 문안까지 진행. 사용자 내용 확정 후 시각자료·디자인·PNG를 제작. 이미 디자인까지 허용된 요청은 반복 확인 없이 진행.’
3. 실제 레퍼런스 파일 열기는 디자인 단계에서 수행한다. 조사 단계는 문서/접근 가능성만 확인해도 된다.
4. Gate 1에 brief.md와 user_notes.md/U ID를 연결한다.
5. Gate 2에 sources.md, claims.md, evidence_review.md, research_brief.md 연결.
6. 기존 Gate 4의 스토리보드는 새로운 storyboard.md 양식으로 보강해 ‘실제 게시 문장 / 필수 조건 / C/S ID / 캡션 이관’ 포함.
7. Gate 3 소재 제작·선택과 Gate 5 렌더링 전에 ‘내용 확정’ 단계 삽입. 이미지 아이디어만은 문안 단계에서 제안 가능.
8. 내용 확정 기록은 approval_log.md. 재확인 예외는 현재 사용자 요청의 범위를 따른다.
9. Gate 8 폴더 구조를 WORKFLOW.md에 맞게 추가. 기존 assets/source/exports/caption/QA는 유지.
10. PNG 해상도 검사와 실제 이미지 육안 검수, 원문 동작 검수는 유지한다.
DESIGN_SYSTEM.md의 CSS·폰트·캔버스와 references/를 변경하지 않는다.
