# 입력 예시 — 아킬레스건 봉합술 후 스트레칭
상태: INPUT / 연구 미확인 / 게시용 문안 아님

- 주제: 아킬레스건 봉합술 후 스트레칭을 언제, 어떻게 판단할까?
- 독자: 성인 봉합술 후 재활 중인 일반인
- 핵심 질문: 발목이 뻣뻣하면 더 세게 늘려도 되는가?
- 사용자 필수 의견 U01: 스트레칭 강도와 회복 단계의 관계를 설명하고 싶다.
- 사용자 필수 의견 U02: 힘줄 길어짐과 기능의 관계를 조사해 포함하고 싶다.
- 사용자 필수 의견 U03: ATRA 같은 평가가 무엇을 알려주는지, 무엇을 확정하지 못하는지 설명하고 싶다.
- 사용자 필수 의견 U04: 단순히 ‘하지 마세요’로 끝나지 않고 판단 순서를 주고 싶다.
- 제외: 특정 주차·각도·횟수를 모든 환자에게 동일 처방하는 문구
- 출처: 사용자가 PDF/DOI를 제공하거나 연구 단계에서 검색
- 기존 글과 차별화: 스트레칭 동작 소개보다 판단 기준 중심
- 장수: 6장, 내용이 부족해지면 변경 제안
- 원하는 행동: 현재 허용 범위와 기능을 확인하고 담당 전문가와 진행 강도를 조정

중요: 위 의견은 조사 질문이다. 과도한 스트레칭이 특정 결과를 ‘반드시’ 일으킨다는 결론, ATRA의 진단 성능, 주차별 기준은 아직 검증하지 않았다. 실제 조사 없이 C ID를 VERIFIED로 채우지 않는다.

## 단계별 실행 예시
1. 01_research 프롬프트의 주제/독자/필수 의견에 위 내용을 붙여 넣는다.
2. 접근 불가 문헌은 확인 범위를 기록한다.
3. 03_finalize_brief로 sources/claims/review/research_brief를 만든다.
4. 네 파일을 content/achilles-postop-stretching/research/에 전달한다.
5. 04_storyboard로 게시 문장 초안을 받는다.
6. U01~U04 반영 위치와 표현 강도를 확인하고 수정한다.
7. 내용 확정 후 06_design을 실행한다.
